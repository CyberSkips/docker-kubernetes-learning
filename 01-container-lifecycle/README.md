\# Docker Container Lifecycle and Management



\## 1. Objective



Learn how to create, inspect, access, stop, restart,

and remove a Docker container.



\## 2. Environment



\- Operating system: Windows 11

\- Terminal: Command Prompt

\- Container runtime: Docker Desktop

\- Image: nginx:latest

\- Container name: nginx-lab



\## 3. Concepts Learned



\- Docker images and containers

\- Container lifecycle

\- Detached mode

\- Host-to-container port mapping

\- Container inspection

\- Container logs

\- Container removal



\## 4. Implementation



Document the commands used to:



1\. Download the Nginx image.

2\. Create and start the container.

3\. Inspect its status and port mapping.

4\. Access the web server.

5\. Read the container logs.

6\. Stop and restart the container.

7\. Remove the container.

Explain the difference between:



\- Images and containers
